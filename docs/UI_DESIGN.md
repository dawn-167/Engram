## 2. 视觉风格

- **主色**：星云紫 `#6C5CE7`（rgb 0.424, 0.361, 0.906），呼应 NexusHub 家族色。
- **窗口**：Nexus 标准毛玻璃浮动窗（`NXWindowStyle`），`popover` 材质 + 主题色 12% 叠加层，圆角 12pt，0.5pt 描边。
- **卡片**：不透明白底（明 92% / 暗 16%），圆角 12pt，柔和投影。不透明卡片规避 KeyHub 记录的非 Retina 半透明字体模糊问题。
- **文字**：主文字 `labelColor`，次要 `secondaryLabelColor`，弱化 `tertiaryLabelColor`，明暗模式自适应。
- **字体**：标题 SF Pro Bold，正文 SF Pro Regular，英文单词/句子用 SF Mono Semibold。
- **状态色**：成功绿 `#27AE60`、错误红 `#E74C3C`、警示橙 `#F39C12`、信息蓝 `#2980B9`。

## 3. 布局

- **窗口尺寸**：940 × 640pt，最小 940 × 600，固定宽度、纵向可缩放。
- **左侧栏**：196pt 固定宽，品牌区（Engram + 英语记忆引擎）、6 项导航、底部连续天数 + 热键提示。
- **内容区**：左右各 24pt 内边距，页面容器翻转坐标自顶向下布局。
- **导航选中态**：主色 14% 背景 + 主色文字与图标。

## 4. 页面设计

### 4.1 学习中心（首页）
- 顶部：大标题 + 日期（中文格式）。
- 五维统计磁贴：待复习（可点击直达复习）/ 今日练习 / 连续天数 / 已学条目 / 已掌握。
- 学习模块区：4 张可点击模块卡（图标 + 名称 + 一句话描述）。
- 底部卡：今日新学目标进度条 + 最近 7 天活跃柱状图。

### 4.2 单词打字
- 顶部：词库下拉 + 重新开始。
- 中部：中文释义（26pt）、音标、待输入单词（40pt 等宽，逐字母着色：已输入绿 / 待输入灰 / 错误红闪）。
- 统计：WPM、正确率。
- 底部：朗读单词、跳过（Tab）。
- 完成一组：总结面板（速度 / 正确率 / 再来一组）。

### 4.3 连词造句
- 顶部：句库下拉。
- 中部：中文句意、已选词块区（绿色胶囊）、答案句（完成后绿色显示）、反馈文字。
- 底部：打乱词块区（紫色胶囊，流式换行）。
- 交互：点选词块 → 前缀校验 → 正确加入 / 错误提示；点已选词块 → 回退到该位置。

### 4.4 口语私教
- 顶部：场景句库下拉。
- 中部：目标句卡片（英文 + 中文 + 实时识别文本）。
- 评分区：大号分数（按等级着色）、等级 + WPM、漏读词 + 识别内容。
- 控制：听示范（蓝）、按住录音（紫，点击切换开始/停止）、上一句 / 下一句。

### 4.5 复习
- 顶部：进度 x/y。
- 卡片：来源标签 + 正面中文提示，点击/空格翻面显示英文答案 + 音标 + 附加说明。
- 四档评分按钮：忘记（红）/ 困难（橙）/ 良好（蓝）/ 简单（绿）。
- 空状态：今日复习完成 + 回学习中心按钮。

### 4.6 学习统计
- 核心成就：连续天数 / 累计学习 / 已掌握 / 打字正确率。
- 分模块：打字单词 / 造句 / 口语 / 复习累计量。
- 最近 7 天练习量柱状图。

## 5. 交互细节

- 打字页按键直接按物理键码映射字母，保证中文输入法下也能稳定输入。
- 打字输错任一字母 → 整词重置 + 红色闪烁 180ms。
- 造句错选 → 不加入、文字提示，不打断当前已选。
- 口语录音中按钮变为「停止识别」，识别结束自动评分并写入记忆曲线。
- 复习没记住（忘记）→ 本轮末尾再出现一次。
- 所有模块练习完成后自动 TTS 朗读英文，加深听觉记忆。
