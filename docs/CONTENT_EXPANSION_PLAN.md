# Engram 内容扩展建议（2026-09-01）

> 背景：Engram 当前内容量明显不足（81 词 + 54 句 = 135 条），而一个完整四级词表有 4000+ 词。
> 本文件记录内容丰富的分层建议，供后续落地参考。

---

## 一、优先级最高：扩充词库（最直接、价值最大）

| 词库 | 建议规模 | 可靠来源（许可注意）|
|------|---------|-------------------|
| 完整 CET-4 | ~3500-4500 词（现仅 49 条占位）| 教育部考试院公开大纲词表（无版权风险）；GitHub 整理版 JSON/CSV，注意来源标注 |
| 完整 CET-6 / 考研 | 各 ~2000-3000 | 同上 |
| 程序员英语扩编 | 32 → 500-1000（按领域分层：后端/前端/云/AI）| 开源"程序员英语"词库 + 自行整理 |
| 高中/初中基础词 | 各 ~1500-2000 | 公开课标词表 |

**可靠性关键**：README 已规避 Anki 的 AGPL——词库同理。优先选**无版权争议的公开词表**（考试大纲、COCA/BNC 词频表）；若参考 Qwerty Learner / Earthworm 词库 JSON，须先确认其许可（README 只说明"借鉴机制"，词库许可要单独看）。

## 二、次优先：句子与口语场景扩展

- 句子库：daily 20 + business 14 → 按主题扩到 200+（旅行/餐饮/电话/面试/会议/医疗，每主题 20-50 句）；已有 `level`（beginner/intermediate/advanced）与 `scene` 字段，正好支持
- 口语场景：20 → 100+，可加"问答对"形态（问句-答句配对），配合现有 LCS 发音评分更有用

## 三、工程层面：schema 轻量扩展（支撑内容质量）

现有字段 `id/text/phonetic/translation/example/exampleZh/deck` 已够基础，建议**可选新增**（向后兼容，不破坏旧数据）：

- 单词：`wordFamily`（词根词缀）、`synonyms/antonyms`、`frequency`（词频标签，来自 COCA）、`level`
- 句子：`topic`、可选 `audioHint`
- **同步扩展 `validate_content.py`**：增加音标格式校验、translation 非空、scene/level 枚举白名单——扩充内容时校验必须跟上（几千条数据靠手工检查不现实）

## 四、建议落地顺序（避免一次性吞太大）

1. **第一批**：完整 CET-4 词表（~4000）+ 扩展校验脚本 → 最大用户价值，格式固定
2. **第二批**：程序员英语扩编 + 主题句子 100+
3. **第三批**：CET-6/考研 + 词根词缀字段
4. **数据量提醒**：JSON 全量加载在几千词（约 1-3MB）完全没问题，暂不需 SQLite；若未来上 2 万+ 词再考虑懒加载

## 附：可靠数据来源清单（候选）

- CET-4/6 词表：教育考试院公开大纲（无版权风险）
- COCA 20000 词频表：BYU 免费公开，适合加"频率"元数据
- BNC 词频表：同 COCA 定位
- Oxford 3000/5000：牛津官网公开词表（有使用条款，需确认）
- 开源项目词库：Qwerty Learner（需查许可）、Earthworm 句库
- 编程英语：GitHub 开源"程序员英语"词库
- 音标：开源工具生成（espeak 等）或半自动整理
